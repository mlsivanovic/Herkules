# Herkules — plan implementacije (production-ready PWA za trening log)

Mozgalica ostaje netaknuta (read-only referenca). Sav kod ide u prazan `/Users/milosivanovic/GIT/Projekti/Herkules`. UI i kod na engleskom; komunikacija i dokumentacija mogu biti mešovite (README na engleskom).

## 0. Utvrđene odluke
- **Stack (verzije kao u Mozgalici, međusobno kompatibilne):** npm, React 19 + react-router-dom 7 (`HashRouter`), Vite 8, TypeScript ~6.0 **strict mode**, `@supabase/supabase-js` 2.x, Vitest 4 (node env), Playwright (novo), oxlint, `vite-plugin-pwa` 1.3 (`injectManifest`, custom `src/sw.ts`, ručna registracija u `src/pwa.ts`, toast „Update available"/„Ready offline"), `idb` za IndexedDB, `sharp` (samo dev) za generisanje PNG ikona. CI na Node 22.
- **Test backend:** poseban remote Supabase **test projekat** — kredencijali u `.env.test.local` (gitignored); RLS/E2E testovi se graceful preskaču kad env nije podešen. Productio projekt se konfiguriše po SETUP.md.
- **Git:** `git init -b main`, logični commit-i po fazama, `remote add origin https://github.com/mlsivanovic/Herkules.git`, push na postojeći `main`.

## 1. Scaffold + dizajn sistem

- `tsconfig` project-references obrazac + `strict: true`; `.oxlintrc.json`; `.gitignore`; `.env.example` (samo `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
- `index.html`: inline pre-paint tema skripta, `theme-color`, apple meta, `%BASE_URL%` linkovi.
- Dizajn tokeni `src/styles/theme.css`: slate/navy osnova + blue/teal akcenat, sistemski font, light/dark preko `data-theme` + localStorage (Mozgalica obrazac); `global.css`: kontrole ≥44px, kontrast, loading/error/empty stanja, upotrebljivost od 360px; desktop bočna navigacija (≥768px), mobilno bottom nav.
- Ikone: original dizajn `design/icon-source.svg` (+ maskable varijanta sa safe-zone), `scripts/generate-icons.mjs` → `public/icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `favicon.svg`.

## 2. Supabase migracije (`supabase/migrations/`, naming `YYYYMMDDHHMMSS_*.sql`)
1. **init**: `pgcrypto`; helper `fn_touch_updated_at`; 9 tabela — `profiles` (unit_system default 'metric', week_start default 'monday'), `exercises` (owner_id NULL = sistemska; category `strength|cardio|mobility`; measurement `weight_reps|reps|duration|distance_duration`; muscle_groups/equipment tekstni nizovi; HTTPS CHECK na video_url; is_archived), `workout_templates`, `template_items` (position, planned_sets, targeti kg/reps/s/m, rest_seconds, superset_group UUID za superset/circuit grupisanje), `recurrence_rules` (weekly + weekdays + start/end date), `schedule_items` (tačno jedan od scheduled_date / recurrence_rule_id), `workout_sessions` (status `in_progress|completed`, partial unique index = najviše jedan aktivan trening po korisniku), `session_exercises` (**snapshot** name + measurement + position — istorija se ne menja kasnijim izmenama kataloga), `workout_sets` (weight_kg/distance_m/duration_s, CHECK nenegativno, RPE CHECK 1–10). `created_at`/`updated_at` svuda + indeksi; trigger na `auth.users` kreira `profiles` red. Jedinice u bazi: kg, m, s.
2. **rls**: deny-by-default (REVOKE pa granularni grantovi, Mozgalica obrazac). Roditelji: `owner_id = auth.uid()`; child tabele preko EXISTS parent provere (`workout_sets` dva nivoa kroz `session_exercises` → `workout_sessions`); sistemske vežbe: SELECT za authenticated, upis nemoguć.
3. **seed**: tačno 15 sistemskih vežbi (8 strength / 4 cardio / 3 mobility) sa mišićnim grupama, opremom i instrukcijama; `video_url` ostaje NULL (linkovi se ne izmišljaju).

## 3. Frontend arhitektura
- `lib/supabase.ts` (singleton getter + `backendConfigured` flag), `lib/auth.tsx` (AuthContext: registracija sa email redirect, prijava, reset lozinke, update password, odjava), ručni tipovi `types/db.ts`, repo funkcije `lib/api.ts`.
- **Čiste domenske funkcije** (sve pod unit testovima): `lib/units.ts` (kg↔lb, m↔km/mi, formatiranje trajanja), `lib/recurrence.rs` → `lib/recurrence.ts` (nedeljno ponavljanje, start/end granice, izvedeni statusi datuma), `lib/metrics.ts` (volumen, Epley e1RM, PR detekcija, weekly volumen, sets po mišićnoj grupi, streak, adherence), `lib/validation.ts`.
- **Offline sloj:** `lib/db.ts` (IndexedDB preko `idb`: lokalni mirror podataka + outbox), `lib/syncQueue.ts` (idempotentne operacije — client-generated UUID PK + upsert; redosled po FK session→exercise→set; retry); sync okidači: start aplikacije, `online` događaj, focus/visibility, kratki debounce; „Pending sync" indikator; **odjava prvo pokušava sync**, offline odjava traži izričitu potvrdu odbacivanja lokalnih izmena.
- **Rute** (HashRouter, gate u `AppLayout` kao u Mozgalici): javne `#/login`, `#/signup`, `#/reset-password`, `#/update-password`; zaštićene: `#/` Today, `#/calendar`, `#/routines` + `#/routines/:id`, `#/exercises` + `#/exercises/:id`, `#/progress`, `#/settings`, `#/workout`, `#/history/:id`.
- **Sekcije:** Today (današnji plan + aktivni trening + brzi start), Calendar (mesecni prikaz, statusi planned/in-progress/completed/skipped; zakazivanje na datum ili weekly sa opcionim end date; izmena pravila ne dira istoriju), Routines (editor: reorder, planned sets, targeti, rest, notes, superset/circuit grupe), Exercises (filteri po kategoriji; custom editor + archive; sistemske read-only), **Workout** (trajanje treninga, prethodne vrednosti po vežbi, rest timer, RPE 1–10, notes, dodaj/ukloni/reorder/swap vežbu, unos za sva 4 measurement tipa, finish i offline — sve se odmah piše u IndexedDB), Progress (ukupni trening, streak, adherence, trajanje, weekly volumen, sets po grupi, PR lista, SVG grafikoni po vežbi — lagane custom SVG komponente), Settings (units, week start, tema, odjava).
- `#/history/:id`: pregled i **naknadna ispravka** završenog treninga (menja samo session snapshot, ne rutinu).

## 4. Testovi
- **Unit** (vitest node env): konverzije, recurrence datumi, volumen/e1RM/PR, validacija, sync queue reconciliation (injektabilan transport/storage po Mozgalica obrascu).
- **RLS integration** (vitest, pokreću se samo uz `.env.test.local` sa test projektom): dva korisnika kreirana `signUp`-om sa random emailovima → dokaz međusobne izolacije preko svih 9 tabela + sistemske vežbe read-only; graceful skip bez env-a.
- **Playwright E2E** (mobile viewport ~390×844, graceful skip bez env-a; test projektu se isključi email konfirmacija po SETUP.md): registracija/prijava, custom vežba, rutina, ponavljajući plan, pokretanje treninga, unos svih tipova merenja, završavanje, istorija; **offline scenario**: trening započet online → `setOffline(true)` → unos i finish → reload bez gubitka → online → potvrda sinhronizacije; provera update prompta, teme, pristupačnih naziva kontrola i direktng otvaranja hash rute.
- **CI**: `.github/workflows/deploy.yml` (push na main): checkout@v7 → setup-node@v7 (Node 22, npm cache) → `npm ci` → oxlint → vitest → build sa `VITE_*` iz GitHub **Variables** → configure-pages@v6 → upload-pages-artifact@v5 → deploy-pages@v5; poseban conditional E2E job (pokreće se tek kad su test-projekat secrets postavljeni) + `keepalive.yml` za free-tier Supabase.
